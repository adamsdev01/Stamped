# Stamped
Built for the OpenAI WebMCP Challenge.

Stamped is a WebMCP-powered career assistant that lets AI agents work alongside job seekers directly in the browser. Upload a resume and an agent — running in ChatGPT's in-app browser or Chrome with WebMCP enabled — can call tools registered via document.modelContext to parse the resume into structured data, score it against open job postings, and draft a tailored cover letter for any match, all without leaving the page. Built on .NET/Blazor with EF Core, Stamped keeps one action deliberately agent-proof: submitting an application stays a manual, button-only step in the UI, so no agent path can submit on the user's behalf.
